# ☕ Syarifah Ni'mah — Hidden Gem & Lifestyle Lokal

> Personal Blog dengan konsep Vintage, Old Jakarta, dan Lifestyle Lokal.

Website ini merupakan blog personal milik **Syarifah Ni'mah** yang menggabungkan biodata pribadi dengan rekomendasi lifestyle dan tempat menarik di Jakarta.

Website dibuat dengan konsep **vintage editorial magazine** menggunakan warna cokelat, cream, beige, dan espresso.
